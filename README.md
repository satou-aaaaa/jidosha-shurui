# 自動車の種類あて（jidosha-shurui）

車両総重量・最大積載量・乗車定員・総排気量・大きさと速さを読んで、道路交通法の8つの自動車の種類（大型・中型・準中型・普通・大型特殊・大型自動二輪・普通自動二輪・小型特殊）のどれかを当てる1日5問の学習ゲーム。正解したら、その種類がどのなかまか（重さ・人数で分けるなかま・二輪・特殊な形）も選ぶ。中学・高校の社会や、交通のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/jidosha-shurui/>

- 中身は e-Gov 法令検索の道路交通法施行規則 第2条（<https://laws.e-gov.go.jp/law/335M50000002060>）の自動車の種類の表に書いてあることだけです。問題の数は作り話で、表の境目（以上・未満・超え）から答えが決まります。
- 説明は条文を短く言いかえたものです。内閣総理大臣が指定する車や、細かい例外は省いています。公式の情報の代わりではありません。どの免許でどの車を運転できるかなど運転免許のことは、都道府県の警察（運転免許センター）の案内で確かめてください。運転免許の試験の対策の代わりにもしません。
